### How to test special effects

1. Complete onboarding (tap through welcome → rules → location → profile).
2. On **Discover**, drag a profile card to:
   - **Trash** (bottom-left, white button) → dark vignette fade + gray particles + whoosh sound
   - **Heart** (bottom-right, red button) → big red heart burst + pink particles + chime sound
   - **Spark Rose** (center, blue rose) → super-like burst with blue rose particles
3. Or **tap** the trash/heart/rose buttons directly.
4. **Sound:** click anywhere on the page first (browser autoplay rule), then like/pass again.
5. **Match demo:** like **Mia** (Crush spotlight profile) → full-screen match → **Start talking** or **Keep looking**.
6. **Badges:** Ava shows **Most Compatible**; Mia shows **Crush** spotlight ring.
7. **Daily batch:** top banner shows "Today's picks · X of Y left" (Coffee Meets Bagel pattern).

## Run locally on your machine

For a permanent setup on your computer:

```bash
git clone https://github.com/MonMonMars/New-APP01.git
cd New-APP01
npm install
npm run web
```

Open http://localhost:8081

## Phone (best experience)

```bash
npm start
```

Scan the QR code with **Expo Go** — drag, haptics, and sound work best on a real device.
